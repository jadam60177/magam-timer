# 🌲 마감의 숲 집필 타이머

글 쓰는 프로그램 창에서 **입력하고 있을 때만** 시간이 흐르는 집필 타이머예요.
마감의 숲 작가님들을 위해 만들었어요.

- 새벽 · 아침 · 낮 · 오후 · 저녁 · 밤, 시간대에 맞춰 바뀌는 작업실 배경
- 시간대가 바뀔 때, 정시마다 살짝 알려 줘요 (작업하다 보면 시간 가는 걸 모르니까요)
- 하루 목표 시간 · 2주/30일 기록 그래프
- 작게 보기 (아무 데나 두 번 클릭)
- 감지할 프로그램 고르기: 한글 · 워드 · 메모장 · 스크리브너 · 구글 문서, 그리고 "열린 창에서 고르기"로 아무 프로그램이나 웹 연재 편집기도

## 받는 법

오른쪽 **Releases** → 가장 위 버전 → `MagamTimer.exe` 받기 → 더블클릭.
처음 켤 때 파란 경고창이 뜨면 **추가 정보 → 실행**.

## 안심 메모

- 인터넷 연결 없음
- 키보드 내용을 보지 않음 (윈도우가 알려 주는 "마지막 입력 시각"과 마우스 위치만 봄)
- 기록은 `%APPDATA%\MagamForestTimer` 에만 저장 (설정 → 기록 폴더 열기)
- 지우고 싶으면 exe 파일과 위 기록 폴더를 지우면 끝

## 만든 것들

- 글꼴: 주아(Jua, 우아한형제들, SIL OFL 1.1) + DejaVu Sans 기호 → `글꼴_라이선스.txt`
- 새 버전 만들기: `v1.0.1` 처럼 태그를 올리면 깃허브가 윈도우에서 exe 를 만들어 Releases 에 올려요
